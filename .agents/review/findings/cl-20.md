# cl-20: Connected geometry can overwrite embedded profile evidence

**Severity**: MEDIUM — Save JSON or Save to Library can silently relabel a
profile with a different physical layout than the one its keymap and lighting
were authored against.
**Status**: Verified
**Branch**: —
**Commit**: `1d6f101f953d190afeaff72be3b25df34ca140f9`

## Evidence

- `am_configurator/profile_metadata.py:302-317` removes embedded metadata and,
  whenever `key_layout` is supplied, rebuilds evidence from that layout without
  resolving or comparing the embedded signature.
- `am_configurator/server.py:2914-2925` accepts caller-supplied `key_layout` at
  the export endpoint.
- `am_configurator/server.py:3159-3188` accepts the same override for Save to
  Library.
- `am_configurator/web/app.js:1214` and `am_configurator/web/app.js:1310-1316`
  supply the connected device layout when one is loaded.
- The write boundary correctly treats the same embedded-versus-live divergence
  as a hard mismatch at `am_configurator/server.py:4174-4182`.

The intake reproduction attached embedded evidence X to a profile, supplied a
different valid connected layout Y to `portable_profile()`, and confirmed the
result did not preserve X's signature.

## Predicted observable failure

A profile authored for layout X is opened while layout Y is connected. Hardware
write correctly blocks, but Save JSON or Save to Library succeeds and replaces
the embedded X evidence with Y. Reopening the saved profile presents its
Per-key data on the wrong physical geometry without any warning.

## What

The portable-save path gives optional connected geometry higher authority than
valid evidence already embedded in the document, contradicting the approved
"embedded evidence wins" contract.

## Approach

`portable_profile()` now validates both sources and compares their canonical
signatures before remembering evidence or returning portable bytes. Matching
connected geometry retains the canonical embedded evidence and reports its
source as embedded; a mismatch raises one task-language error before export or
Library publication. Legacy profiles without valid embedded evidence retain
the connected-layout path.
