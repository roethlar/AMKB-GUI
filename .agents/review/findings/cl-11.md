# cl-11: Sessionless renders consume and depend on the preview-session LRU

**Severity**: MEDIUM — ordinary full renders can evict an unrelated live preview
session or be cancelled by cache eviction even though no newer render superseded
their destination.
**Status**: Open
**Branch**: —
**Commit**: —

## Evidence

- `am_configurator/media_composition.py:1946-1950` creates a retained preview
  session whenever the existing full-render route omits `preview_session_id`.
- `am_configurator/media_composition.py:1493-1510` applies the two-entry LRU
  limits and inserts that unreferenced session, while the render cleanup at
  `am_configurator/media_composition.py:1985-1986` only updates the active count.
- `am_configurator/media_composition.py:1850-1877` requires every render's
  prepared session to remain in that LRU, including sessionless legacy renders.
- The pre-LSR-2 renderer had no preview-session residency dependency for this
  route. The LSR-2 requirement explicitly preserves existing full-render
  behavior while adding optional prepared sessions.

The intake reproduction prepared one explicit session, issued two sessionless
renders, and then requested the explicit session's source frame. The request
failed with `This media preview session is no longer available.` even though
its Library item had not changed.

## Predicted observable failure

A user can keep media A open in the live Source/Board workflow while ordinary
full renders for media B silently consume both preview-session slots. Media A's
next selected-frame or source-frame request then fails as an expired session.
Concurrent sessionless renders can also evict one another and return HTTP 409 or
an irrelevant preview-session error despite targeting independent destinations.

## What

The new bounded cache conflates explicit reusable preview sessions with
one-request legacy rendering. A sessionless caller neither requested nor can
reuse the retained entry, but it pays the cache capacity and residency
requirements anyway.

## Approach

Decode sessionless full renders into transient prepared sources that are never
inserted into the preview LRU. Keep explicit `preview-session` sessions retained
and residency-checked. Sessionless epoch checks remain destination-scoped but
depend only on coordinator lifetime and the latest epoch, not cache membership.
Do not publish an unusable preview-session identifier for a transient render.
