# cl-21: Applied AM Master frames remain frozen and cannot be edited

**Severity**: HIGH — Apply succeeds with correct colors, but subsequent paint,
Fill frame, and Clear frame operations throw and leave the imported frames
effectively read-only.
**Status**: In progress
**Branch**: —
**Commit**: —

## Evidence

- `am_configurator/web/app.js:693-697` recursively freezes every object and
  array in the immutable server import report.
- `am_configurator/web/app.js:4552-4574` passes the report's
  `lighting.mapped_result` directly into the live document mutation.
- `am_configurator/web/app.js:4915-4923` creates new frame wrapper objects but
  assigns each imported `colors` array directly to `frame_RGB`.
- `am_configurator/web/app.js:4856` and `am_configurator/web/app.js:4899-4900`
  later mutate those arrays by indexed assignment and `fill()`.

An independent Node reproduction of the exact freeze-and-assignment shape
confirmed both operations throw `TypeError: Cannot assign to read only property
'0'` and that the live document's `frame_RGB` remains frozen.

## Predicted observable failure

Open a compatible Neon document, import AM Master AM 80 lighting-only JSON,
Apply it, then paint a pixel or use Fill frame / Clear frame. The edit throws,
does not mark the document dirty, and can still consume an Undo checkpoint.
Imported frames become editable only after an Undo-created clone or replacement
frame breaks the shared frozen reference.

## What

The immutable transient import report crosses the Apply boundary by reference.
The live document therefore inherits frozen color arrays even though document
editing assumes every `frame_RGB` is mutable.

## Approach

`applyLedResultToPage()` now copies each validated canonical color array when it
constructs mutable document `frame_RGB` data. The transient import report stays
recursively frozen, while the live document owns both Head and Per-key arrays.
The regression guard extracts and executes the actual production function in a
Node VM, edits the resulting frames by indexed assignment and `fill()`, and
confirms the frozen input report remains unchanged.

## Files changed

- `am_configurator/web/app.js` — copy each mapped color array at the live
  document boundary.
- `tests/web/lighting_shell.test.js` — execute the production conversion with a
  recursively frozen two-track input and prove mutable, unshared output.
- `.agents/review/findings/cl-21.md`, `.agents/review/index.md`,
