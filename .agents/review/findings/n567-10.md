## Predicted observable failure

## What

See the pass summary in `.agents/review/index.md`: the protocol modules are
sound in isolation and the seams between them and the existing application were
not built. This finding is one of those seams.

## Approach

The HID identity gate projects the device-supplied Vial KLE definition into
bounded browser geometry and publishes it with the deep device record. The
browser renders Neon only from that geometry, preserves it across shallow
rescans, and filters the shared palette to codes that Neon can encode.

An authenticated assignment endpoint delegates Neon validation to the
canonical Vial-to-QMK translator. Palette and raw-code assignments pass through
that gate before document mutation, with request ownership preventing a stale
response from changing a newly selected key.
